# verilog-simulator-EEGR471-RY
Verilog Simulator

TO USE EVENT SIMULATOR:
Run line below in command line


[python Event_Cycle_Sim/Event_Sim.py python "ABSOLUTE PATH FOR VERILOG FILE" "ABSOLUTE PATH FOR VECTOR INPUT"]


The output is saved under Event_Cycle_Sim/Result_Vectors/Event_Vectors

TO USE CYCLE SIMULATOR:
Run line below in command line

[python Event_Cycle_Sim/Cycle_Sim.py python "ABSOLUTE PATH FOR VERILOG FILE" "ABSOLUTE PATH FOR VECTOR INPUT"]


The output is saved under Event_Cycle_Sim/Result_Vectors/Cycle_Vectors
